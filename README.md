# mcd-smart-order —— 麦当劳「预算 + 热量」智能点餐推荐 Skill

## 项目介绍

一个 WorkBuddy 用户级 Skill，解决一个具体问题：**在预算和热量双重约束下，帮你搭配一顿麦当劳**。

你说一句"30 块以内、600 大卡以内，帮我配一顿麦当劳"，它会自动完成：

1. **定位门店**：按你的位置查附近门店（到店自取 / 得来速 / 麦乐送外送）
2. **拉取真实数据**：通过 mcd-mcp 连接器获取门店在售菜单、官方营养成分表、你的优惠券
3. **智能关联**：把菜单与营养表按名称匹配，得到每个商品的准确价格和热量
4. **组合优化**：调用内置脚本 `scripts/combo_optimizer.py`，枚举「主餐 + 小食 + 饮品」组合，筛出同时满足预算和热量上限的方案
5. **输出推荐**：返回 2-3 套方案，每套含搭配清单、总价、总热量、预算/热量余量，并按不同侧重排序（均衡 / 最省热量 / 最高蛋白 / 性价比）
6. **确认下单**：你选定方案并确认价格后，自动创建订单

设计原则：

- **AI 与脚本分工明确**：AI 负责理解意图、模糊匹配、串联工具；脚本负责确定性数学计算，快且稳
- **数据不造假**：营养表匹配不到的商品（限定款/新品）如实标注"热量未知"，绝不出具编造数字；价格一律以 `calculate-price` 实时计算为准（含优惠）
- **下单必须确认**：任何下单动作都需要你明确确认后才会执行

## 安装方法

### 前置条件

- WorkBuddy 桌面端
- **麦当劳连接器（mcd-mcp）**：需已连接并登录麦当劳账号（在连接器管理中启用）

### 安装

**方式一：使用分发包（推荐）**

将 `mcd-smart-order.zip` 解压到 WorkBuddy 的用户级技能目录：

```
C:\Users\<你的用户名>\.workbuddy\skills\mcd-smart-order\
```

解压后确认目录内有 `SKILL.md` 即安装成功，重新打开对话即可生效。

**方式二：从源码安装**

把整个 `mcd-smart-order/` 目录复制到上面的路径，或复制到某个项目的 `.workbuddy/skills/` 目录下（仅该项目可用）。

### 验证安装

新开一个对话，输入：

> 30 块以内、600 大卡以内，帮我搭配一顿麦当劳

如果 AI 开始询问你的位置并查询门店，说明 skill 已正确触发。

## 使用示例

**示例 1：减脂餐**

> 帮我搭配一顿麦当劳，预算 35 元，热量控制在 600 大卡以内，我在科技园附近，到店自取

输出：2-3 套方案，例如「板烧鸡腿堡 + 无糖热茶：31.5 元 / 430 大卡」。

**示例 2：指定口味偏好**

> 25 元以内、700 大卡以内吃一顿麦当劳，不吃辣，外送到我家

输出：自动排除辣味商品，外送方案会预留配送费再计算搭配。

**示例 3：调整排序偏好**

> 预算 30 元，热量不限，我想吃得饱一点

输出：按蛋白质最高排序，推荐最饱腹的组合。

**示例 4：确认下单**

方案展示后回复"就要第 2 套"，AI 会先展示含优惠的实付价格，你确认后自动创建订单并给出支付引导。

## 目标用户

- **减脂 / 健身人群**：想吃麦当劳又怕热量超标，需要精确到 kcal 的搭配
- **预算敏感人群**：学生党、上班族，想在固定预算内吃得最划算
- **选择困难户**：面对菜单纠结半天的人，直接要 2-3 套现成方案
- **效率党**：一句话搞定"选门店 → 配餐 → 下单"全流程

## 常见问题

**Q：热量数据准吗？**
A：来自麦当劳官方营养成分表，为标准配方的静态数据；特制选项（去酱、加料）的热量变化不计算在内。匹配不到的商品会标注"热量未知"。

**Q：显示的价格是最终价格吗？**
A：推荐阶段是估算，下单前会用 `calculate-price` 按当前门店和优惠券实时计算实付价，以那个为准。

**Q：为什么有些商品没出现在推荐里？**
A：可能是热量数据缺失、超出约束被脚本过滤，或该门店当前未在售。

**Q：会自动帮我下单吗？**
A：不会。必须由你确认具体方案和实付价格后，才会创建订单。
